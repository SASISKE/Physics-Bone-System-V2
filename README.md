# Deepsi — PhysBone v2 (актуальная модель)

Копия текущей установленной модели Deepsi и её `script.lua`, подключённая к PhysBone System v2. Исходный аватар `Animation_Physics_Studio_Test` не изменён.

## Запуск

1. В Figura выбери аватар **Deepsi — PhysBone v2 (актуальная модель)** и перезагрузи его.
2. Нажми **F8**: откроются основные настройки. Наведи курсор на строку для подсказки; **Подробнее** открывает точные параметры.
3. В этой копии уже включён профиль хвоста `tail.001` из `physics_bone_preset.lua`. Если Figura уже сохранила локальный профиль для этой копии, он имеет приоритет.
4. Нажми **Сохранить** после своих изменений.

Профиль хвоста использует те же 11 pivot-групп `tail.001`–`tail.011`, что и ручной тест PhysBone v2. Изменения модели и анимаций можно продолжать делать в Blockbench; интерфейс и физика находятся в Lua-файлах `physics_bone_*.lua`.

Для включения старого Physics Studio используй исходную аватару `Animation_Physics_Studio_Test`. В этой V2-копии старый скрипт не запускается, чтобы оба редактора не перехватывали F8 одновременно.
